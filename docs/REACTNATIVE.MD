# Core Components and Native Components

React Native là một framework mã nguồn mở để xây dựng ứng dụng Android và IOS bằng cách sử dụng React và Native gốc của 2 hệ điều hành

- Bạn sử dụng Javascript để truy cập API và mô tả giao diện ứng dụng bằng cách sử dụng các thành phần của React
- Sau đó, React Native sẽ tự động chuyển đổi thành các thành phần gốc của hệ điều hành
- Các thành phần gốc này sẽ được sử dụng để xây dựng ứng dụng
- Khi bạn chạy ứng dụng, các thành phần gốc sẽ được sử dụng để hiển thị giao diện

JSX cho phép viết HTML trong JavaScript, giúp mã dễ đọc và trực quan hơn.

Props là dữ liệu truyền từ thành phần cha cho thành phần con.

State là dữ liệu nội bộ của thành phần, phản ánh trạng thái hiện tại của nó.

Lifecycle methods cho phép điều khiển hành vi của thành phần trong các giai đoạn khác nhau của vòng đời
