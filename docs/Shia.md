React Native Skia mang Thư viện đồ họa Skia vào React Native. Skia đóng vai trò là công cụ đồ họa cho Google Chrome và Chrome OS, Android, Flutter, Mozilla Firefox và Firefox OS cũng như nhiều sản phẩm khác.

### Version compatibility:

react-native@>=0.66 and react@>=18 are required. In addition you should make sure you're on at least iOS 13 and Android API level 16 or above. To use React Native Skia with the new architecture, react-native@>=0.72 is required.

## Installation

```bash
yarn add @shopify/react-native-skia
```
